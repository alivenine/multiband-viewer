Multiband Viewer Usability Test

Five tasks from a real technical-imaging job, timed on the current build and on the new one. The main thing to watch is whether people trust an alignment that is wrong. Time matters less.

Before each session

  • Old build: the 6 Nov web version at ba8a58e7.multiband-viewer.pages.dev. New build: multiband-viewer.pages.dev or the Mac app. Use the same browser for both.
  • Image set: the 9 bands in Demo-P2. Clear the app's Local cache first so import isn't instant on the second run.
  • Alternate the order: odd-numbered participants start on the old build, even-numbered on the new. Each person does both builds, so the second run benefits from practice. The alternation evens that out.
  • Aim for 5 participants (conservators or imaging technicians). With 5 you see most of the big problems, and each new person adds less.
  • Don't help unless they're stuck for 2 minutes. If you step in, mark the task Done with help.

“We're testing the software, not you. Please think aloud: say what you're looking for and what you expect to happen. I can't answer questions during a task, but I'll answer everything afterwards.”
