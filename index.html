🔒 Your images never leave this computer

Multiband Viewer runs entirely on your own computer, inside this browser window.

  • Images are never uploaded to any server. There is no server: decoding, alignment, markup and export all run locally.
  • Imported images are cached in this browser's private storage on your disk, so they reopen quickly. Clear it any time under Local cache.
  • The page has a security policy that blocks sending data anywhere, so the browser itself would refuse an upload.
  • Project files and PNG exports are saved only where you choose.
